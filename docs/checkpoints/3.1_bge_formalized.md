# Checkpoint 3.1 — BGEEmbedder Formalized

## What we built
- `BGEEmbedder` formalized with `NAME`, `last_embed_ms`, `embed_numpy()`
- `embedders/__init__.py` — the package export contract every future embedder joins
- `openrouter/free` as the stable generation model alias
- Verified baseline: recall@1=0.900, recall@3=1.000, MRR=0.950

## Core concepts

### 1. The embedder contract
Every embedder follows the same three-method interface:
```python
embed(texts: list[str]) → list[list[float]]    # passages
embed_query(query: str) → list[float]          # queries (may differ from passages)
embed_numpy(texts: list[str]) → np.ndarray     # direct numpy for FAISS
```

The split between `embed()` and `embed_query()` is critical for asymmetric models — queries and passages may need different treatment (prefix, instruction, encoding mode).

### 2. NAME + last_embed_ms — the benchmark contract
Every embedder exposes:
- `NAME: str` — class-level identifier, used by benchmarks to group results
- `dimension: int` — set at load time from the actual model
- `last_embed_ms: float` — timing for the last call, readable by the benchmark

This makes the M3.7 benchmark trivial: iterate embedders, call `embed()`, read `last_embed_ms`.

### 3. embed_numpy() — the performance method
`embed()` returns `list[list[float]]`. To add to FAISS, we convert to numpy. `embed_numpy()` skips the round-trip:
```
embed() path:  model → np.ndarray → .tolist() → list[list[float]] → np.array() → FAISS
embed_numpy(): model → np.ndarray → FAISS
```
On 100K chunks, the round-trip conversion costs seconds. `embed_numpy()` eliminates it.

### 4. BGE asymmetric retrieval recap
BGE uses different treatment for queries vs passages:
- Query: `"Represent this sentence for searching relevant passages: {query}"`
- Passage: no prefix

This asymmetry was learned during contrastive training. Skipping the query prefix measurably hurts recall (5-15% drop in MTEB benchmarks). Our `embed_query()` applies it automatically.

### 5. openrouter/free — never hardcode :free model IDs
Free model availability on OpenRouter rotates constantly — `inclusionai/ling-3.0-flash:free` was available for weeks then disappeared. `openrouter/free` is a stable meta-router maintained by OpenRouter that always points to currently-available free models. Hard-coding a specific `:free` model ID in any project that runs longer than a few weeks is a reliability anti-pattern.

## Interview flashcards

1. **Q:** Why does your embedder have separate `embed()` and `embed_query()` methods?
   **A:** Asymmetric retrieval. Models like BGE, E5, and Instructor treat queries differently from passages — different prefixes, different encoding modes. A single `embed()` call can't express this distinction. Callers use `embed_query()` for user queries and `embed()` for document passages.

2. **Q:** Why is `embed_numpy()` a separate method instead of converting inside `embed()`?
   **A:** Performance. `embed()` returns Python lists for generality (JSON-serializable, cache-compatible). FAISS needs numpy. Converting list→numpy at every FAISS boundary is O(N) overhead. `embed_numpy()` returns native numpy and avoids the round-trip. On 100K chunks, this saves seconds.

3. **Q:** What does `last_embed_ms` enable?
   **A:** White-box timing. External timing wrappers measure wall-clock time including Python overhead. `last_embed_ms` measures pure model inference time. The benchmark reads it directly rather than wrapping each call in `time.perf_counter()`.

4. **Q:** Why is `dimension` set at load time from the actual model?
   **A:** Different BGE variants have different dimensions (384/768/1024). Hard-coding the dimension would break when someone swaps models. Reading from the model at init time ensures correctness regardless of which variant is loaded.

5. **Q:** What happens to openrouter/free when all free models are down?
   **A:** The API returns an error (503 or model-specific error). Our generator wraps every call in try/except and propagates a clear error message. For production, you'd add retry logic with exponential backoff, or fall back to a cached response for known queries.
